# Catatanku

Aplikasi Flutter sederhana untuk menyimpan ide dan catatan harian Dina.

## Fitur

- Splash screen dan halaman masuk.
- Beranda dengan pencarian dan filter kategori catatan.
- Form tambah dan edit catatan dengan pilihan kategori, warna, dan prioritas.
- Detail catatan, hapus, serta pindahkan catatan ke arsip atau pulihkan kembali.
- Halaman arsip dan profil.

Catatan saat ini disimpan sementara selama aplikasi berjalan; belum ada sinkronisasi
atau penyimpanan permanen.

## Menjalankan aplikasi

Pastikan Flutter SDK sudah terpasang, lalu jalankan dari folder proyek:

```powershell
flutter pub get
flutter devices
flutter run
```

Jalankan pengujian widget dengan:

```powershell
flutter test
```
